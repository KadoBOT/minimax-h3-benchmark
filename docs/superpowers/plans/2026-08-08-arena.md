# Arena Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. Work them in
> order; each task ends with a green test run.

**Goal:** Add an A/B/tie arena that only ever offers comparable pairs of runs, and a
leaderboard that ranks the settings those votes are evidence about.

**Architecture:** One new pure domain module (`h3lab/domain/arena.py`) owns the
held/contested partition, pool identity, matchup selection and the standings maths. The Elo
replay in `h3lab/domain/rating.py` is generalised so setting values are ranked by the same
code that ranks runs. The Lab facade exposes three methods, two new routes serve them, and
two new React pages consume them. No database change: fairness is recomputed from each run's
stored config, so votes already in the database are classified correctly.

**Tech Stack:** Python 3.11+ / Pydantic v2 / FastAPI / SQLite; React 19 + TypeScript +
Tailwind v4 + Base UI; pytest, Vitest + Testing Library, Playwright.

## Global Constraints

- Held settings: `mode`, `prompt`, `first_frame`, `last_frame`, `ref_images`, `ref_videos`,
  `ref_video_audios`, `ref_audios`, `ref_image_size`, `aspect_ratio`, `mp`, `duration_s`,
  `rife`, `upscaler`, `widgets`.
- Contested settings: `diffusion_model`, `sampler`, `scheduler`, `steps`, `turbo`, `cache`,
  `cache_enabled`, `cache_preset`, `sol_attn`, `sol_preset`.
- Ignored: `seed`, `clean_vram`. The three sets partition `HASHED_FIELDS` exactly.
- `MIN_DECIDED_VOTES = 4`; a winner needs `wins > losses` and `|wins − losses| > √(wins + losses)`.
- Elo base 1500, K 24, replayed from the whole log.
- `domain/arena.py` performs no I/O and imports only `domain/config.py` and `domain/rating.py`.
- Every ranked row carries its sample size. Speed is a guardrail beside the ranking, never inside it.
- Run `python scripts/gen_types.py` after any API model change, or `tests/test_contract.py` fails.

```python
class Standing(BaseModel):
    """Pairwise strength of one competitor, whatever the competitor is."""

    model_config = ConfigDict(frozen=True)

    key: str
    rating: float = ELO_BASE
    wins: int = 0
    losses: int = 0
    ties: int = 0

    @computed_field  # type: ignore[prop-decorator]
    @property
    def games(self) -> int:
        return self.wins + self.losses + self.ties

    @computed_field  # type: ignore[prop-decorator]
    @property
    def decided(self) -> int:
        return self.wins + self.losses

    @computed_field  # type: ignore[prop-decorator]
    @property
    def win_rate(self) -> float | None:
        return None if self.decided == 0 else self.wins / self.decided


def replay_pairwise(
    games: Iterable[tuple[str, str, str | None]],
    *,
    k: float = ELO_K,
    base: float = ELO_BASE,
) -> dict[str, Standing]:
    """Elo over any competitor key: a run id, a setting value, or a whole loadout."""
    ratings: dict[str, float] = {}
    wins: dict[str, int] = {}
    losses: dict[str, int] = {}
    ties: dict[str, int] = {}

    def seen(key: str) -> None:
        ratings.setdefault(key, base)
        wins.setdefault(key, 0)
        losses.setdefault(key, 0)
        ties.setdefault(key, 0)

    for left, right, winner in games:
        if left == right:
            continue
        seen(left)
        seen(right)
        rating_left, rating_right = ratings[left], ratings[right]
        expected_left = _expected(rating_left, rating_right)
        if winner is None:
            score_left = 0.5
            ties[left] += 1
            ties[right] += 1
        elif winner == left:
            score_left = 1.0
            wins[left] += 1
            losses[right] += 1
        elif winner == right:
            score_left = 0.0
            losses[left] += 1
            wins[right] += 1
        else:
            continue
        delta = k * (score_left - expected_left)
        ratings[left] = rating_left + delta
        ratings[right] = rating_right - delta

    return {
        key: Standing(
            key=key, rating=round(value, 4), wins=wins[key], losses=losses[key], ties=ties[key]
        )
        for key, value in ratings.items()
    }
```

and `replay_elo` becomes a wrapper:

```python
def replay_elo(votes, *, k: float = ELO_K, base: float = ELO_BASE) -> dict[str, EloEntry]:
    """Recompute every run's rating from the whole vote log."""
    table = replay_pairwise(
        ((vote.run_a, vote.run_b, vote.winner) for vote in votes), k=k, base=base
    )
    return {
        run_id: EloEntry(
            run_id=run_id,
            rating=item.rating,
            wins=item.wins,
            losses=item.losses,
            ties=item.ties,
        )
        for run_id, item in table.items()
    }
```
